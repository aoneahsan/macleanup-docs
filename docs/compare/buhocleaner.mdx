# Moving from BuhoCleaner

If one tap is the reason you bought BuhoCleaner, this will feel slower, on
purpose. Flash Clean's place is taken by a preview you read and a confirmation
you give, so you know what is about to go before it goes. The menu bar monitor for
RAM, CPU and fans has no counterpart; keep BuhoCleaner if you watch it.

## Flash Clean and the rest, translated

| In BuhoCleaner | In macleanup |
|---|---|
| Flash Clean | `--all`, the safe batch of sections 0, 3, 5, 7, 8, 9, 15, 18, 22, 26 |
| Xcode cache cleaner | [Section 1](/reference/sections#section-1--xcode-caches-deriveddata-simulators) |
| Flush DNS cache | [Section 20](/reference/sections#section-20--dns--mdns-reset), which also renews DHCP on `en0` |
| Uninstall with leftovers | Sections [21](/reference/sections#section-21) and [12](/reference/sections#section-12--orphaned-app-data) |
| Disk space analyser | [Section 26](/reference/sections#section-26--disk-usage-report), as text |
| Menu bar RAM, CPU and fan monitor | Nothing |

## Your first batch, slowly

1. See what the batch that stands in for Flash Clean would do.

   ```bash
   npx macleanup --dry-run --all
   ```

2. Learn what a preview cannot promise:
   [the honest limits of a preview](/before-you-run/dry-run#the-honest-limits-of-a-preview).

3. Run the batch for real and answer each prompt as it comes.

   ```bash
   npx macleanup --all
   ```

4. Used BuhoCleaner's Xcode cleaner? Section 1 is outside `--all`, so preview it
   on its own.

   ```bash
   npx macleanup --only 1 --dry-run
   ```
