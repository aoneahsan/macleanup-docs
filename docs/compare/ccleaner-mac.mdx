# Moving from CCleaner for Mac

Read this before anything else if you use CCleaner to wipe browsing history:
macleanup will not. Its browser section clears HTTP and code caches in every
profile and leaves history, logins, bookmarks and extensions where they are.
Duplicate photo cleanup has no counterpart either. People who mostly want caches,
temp files and unused apps gone will find each one under a number.

## Where CCleaner's checkboxes went

| In CCleaner for Mac | In macleanup |
|---|---|
| Cache and temporary files | Sections [5](/reference/sections#section-5--user-caches) and [8](/reference/sections#section-8--temp-files) |
| Browser cleaning | [Section 19](/reference/sections#section-19--browser-caches). Safari is advisory only |
| Removing large or unused apps | [Section 21](/reference/sections#section-21) |
| Duplicate photo cleanup | Nothing |
| Scheduling | Pro and Team in the [desktop app](/desktop-app/plans) schedule previews and safe-batch runs |

## Switching your cleaning over

1. Start with the browsers, since that is the part that behaves differently.
   Afterwards pages load slower for a while, and some sites may sign you out.

   ```bash
   npx macleanup --only 19 --dry-run
   ```

2. Now the rest of a CCleaner pass: caches, logs, temp files and update caches.
   The Trash is not touched.

   ```bash
   npx macleanup --profile minimal --dry-run
   ```

3. If you write software, preview the developer profile too. Section 23 is part
   of it, and it deletes permanently.

   ```bash
   npx macleanup --profile dev --dry-run
   ```

4. Run the browser section for real, then open its report.

   ```bash
   npx macleanup --only 19
   ```

## CCleaner's plans and rows, dated

CCleaner's Mac pages did not mention logs, data from removed apps, a disk map,
notarisation or the Mac App Store, or source code. Those rows are dropped from the
table; dropped means unstated, not missing.
