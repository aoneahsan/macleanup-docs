# Moving from CleanMyMac

CleanMyMac decides for you in one window, and it also scans for malware, updates
your software and tunes performance. If you use those, stay with it. macleanup only
cleans: it lists the paths and asks you section by section.

You don't have to choose today. Keep CleanMyMac installed while you try this;
nothing below touches it.

## CleanMyMac's modules, by section number

| In CleanMyMac | In macleanup |
|---|---|
| Old caches and logs | [Sections 5 and 7](/reference/sections#section-5--user-caches), or `--profile minimal` |
| Xcode junk | [Section 1](/reference/sections#section-1--xcode-caches-deriveddata-simulators) |
| Uninstalling an app with its leftovers | [Section 21](/reference/sections#section-21) for idle apps |
| Leftovers from apps already gone | [Section 12](/reference/sections#section-12--orphaned-app-data) |
| Malware scanning, software updates, performance tools | Nothing. macleanup only cleans |

## A first week with both installed

1. Print the section list. You pick by number from here on.

   ```bash
   npx macleanup --list
   ```

2. Preview the weekly sweep, the profile the caches and logs row points to.
   Trash is left alone by it.

   ```bash
   npx macleanup --profile minimal --dry-run
   ```

3. With those paths read, ask what deleted apps left behind.

   ```bash
   npx macleanup --only 12 --dry-run
   ```

4. Before the first real run, read
   [the limits of a preview](/before-you-run/dry-run#the-honest-limits-of-a-preview).
   Section 5 sweeps `~/Library/Caches`, which macOS and your apps refill. Then run
   it alone; the report lands in `~/.macleanup/reports/`.

   ```bash
   npx macleanup --only 5
   ```

5. Miss having a window? [The desktop app](/desktop-app/overview) runs the same
   script. Its [plans](/desktop-app/plans) count real runs only; previews stay free.
