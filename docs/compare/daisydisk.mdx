# Moving from DaisyDisk

People who think in pictures should keep DaisyDisk. macleanup has no map, and its
reports are plain text. What it does have is cleanup sections that already know
where caches, logs and app leftovers live, so you are not hunting for them by eye.
The two do different jobs and sit happily on one Mac.

## The sunburst, said in text

| In DaisyDisk | In macleanup |
|---|---|
| The sunburst disk map | [Section 26](/reference/sections#section-26--disk-usage-report), folder sizes as text |
| Spotting the largest files | [Section 18](/reference/sections#section-18--large-files-report), everything from 500 MB up in `$HOME` |
| Deleting a big file you chose | [Section 24](/reference/sections#section-24--large-stale-files), large and untouched, moved to the Trash |

## Asking where the space went

1. Run the two report sections. Neither deletes anything.

   ```bash
   npx macleanup --only "18,26"
   ```

2. Open the dated `.txt` files in `~/.macleanup/reports/`. That is your map,
   written down.

3. Preview the large files you have not touched in six months. A file counts only
   when both its access and change dates are old, so something big you opened last
   week stays off this list; section 18 is where it shows.

   ```bash
   npx macleanup --only 24 --large-file-size-gb 2 --large-file-days 180 --dry-run
   ```

4. Then preview the space a map never puts a name on: caches, logs and temp files.

   ```bash
   npx macleanup --profile minimal --dry-run
   ```

## DaisyDisk's price and rows, dated

DaisyDisk's pages are about the map. They did not say whether it clears caches or
logs, finds data from removed apps, uninstalls apps, or publishes its source, so
those rows are not in the table. That is silence on their pages, not a "no".
