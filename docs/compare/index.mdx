# Moving to macleanup

**You can run macleanup beside the cleaner you have today.** It keeps no shared
state with any of them, and a preview deletes nothing, so you can compare the two
on your own disk before you drop anything.

Pick the cleaner you use. Each guide says which numbered sections cover what you
do there, which commands to preview first, and what you will not find in
macleanup. The table at the end of each guide is what that maker's own pages
state, with the link and the date. A row they did not state says so.

## Where macleanup falls short

- It is not notarised by Apple and is not on the Mac App Store. The app asks you
  to choose [Open Anyway](/desktop-app/install#gatekeeper) once.
- Its disk report is text. [Section 26](/reference/sections#section-26--disk-usage-report)
  prints folder sizes; there is no visual map.
- There is no undo. Sections 12, 21 and 24 move items to the Trash. Other direct
  deletions need a backup: read [What gets deleted](/before-you-run/what-gets-deleted).

The same comparisons, written for choosing rather than moving, are on the
[macleanup website](https://macleanup.aoneahsan.com/compare).
