# Moving from mac-cleanup-py

Of everything on this list, mac-cleanup-py is the closest neighbour: a command-line
cleaner whose code you can read. If you already run Python and like installing with
pip or Homebrew, it does the job. Moving is mostly vocabulary. Named modules become
numbered sections, and `--only` is how you pick them.

## Modules become section numbers

| In mac-cleanup-py | In macleanup |
|---|---|
| `pip3 install` or `brew install` | `npx macleanup`, or a [git checkout with no Node](/getting-started/installation#method-3--direct-git-checkout-no-node-required) |
| Clear cache | Sections [3](/reference/sections#section-3--package-manager-caches) and [5](/reference/sections#section-5--user-caches) |
| Delete logs | [Section 7](/reference/sections#section-7--logs) |
| A module per tool | `--only` with [section numbers](/reference/sections) |
| A saved set of modules | [Profiles](/reference/profiles) and [`~/.macleanuprc`](/reference/configuration) |

What you gain is section 12 (orphaned app data) and section 21 (unused apps).
Neither one runs as part of `--all`.

## From a clone, with bash and nothing else

1. Clone it and list the sections. No Python, no Node.

   ```bash
   git clone https://github.com/aoneahsan/macleanup.git
   cd macleanup
   chmod +x macleanup.sh
   ./macleanup.sh --list
   ```

2. Preview the three sections that stand in for your module list.

   ```bash
   ./macleanup.sh --only "3,5,7" --dry-run
   ```

3. Wrapping it in your own scripts? The event stream is NDJSON, and
   [`--json-events`](/reference/json-events) documents its schema.

   ```bash
   ./macleanup.sh --only "3,5,7" --dry-run --json-events
   ```
