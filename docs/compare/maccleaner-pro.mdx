# Moving from MacCleaner Pro

MacCleaner Pro is six apps in one bundle; macleanup is one script with 28 sections.
If you use the duplicate finder, the memory cleaner or the visual disk analyser,
those stay with MacCleaner Pro. The cache, log, uninstall and leftover cleaning
lines up with a section number each.

## The six apps, mapped to sections

| In MacCleaner Pro | In macleanup |
|---|---|
| Clear caches and logs | `--profile cache-only` |
| App Cleaner & Uninstaller | [Section 21](/reference/sections#section-21) |
| Apps' leftovers | [Section 12](/reference/sections#section-12--orphaned-app-data) |
| Disk space analyser | [Section 26](/reference/sections#section-26--disk-usage-report), as text |
| Duplicate finder, memory cleaner | Nothing |

## Reading before running

1. Read the script before you let it delete a thing. It is
   [public](https://github.com/aoneahsan/macleanup), and the
   [no-Node checkout](/getting-started/installation#method-3--direct-git-checkout-no-node-required)
   runs it straight from the clone.

2. Preview the cache profile, which is sections `3, 5, 6, 7, 9, 19`.

   ```bash
   npx macleanup --profile cache-only --dry-run
   ```

3. Preview the audit profile to see leftovers, idle apps and folder sizes in one
   listing.

   ```bash
   npx macleanup --profile audit --dry-run
   ```

4. Section 26 only reports, so it is safe to run for real straight away.

   ```bash
   npx macleanup --only 26
   ```
