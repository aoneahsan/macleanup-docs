# Moving from MacKeeper

**macleanup replaces one part of MacKeeper: the cleanup.** Antivirus, the VPN,
adware blocking and breach monitoring have no counterpart here. Sort those out
first if you rely on them, and only then change your subscription.

## What maps to what

| In MacKeeper | In macleanup |
|---|---|
| Junk files and unused apps | [`--profile minimal`](/reference/profiles) and [section 21](/reference/sections#section-21) |
| Uninstaller with leftover removal | Sections [21](/reference/sections#section-21) and [12](/reference/sections#section-12--orphaned-app-data) |
| Antivirus, VPN, adware blocking, identity monitoring | Nothing |
| 24/7 chat support | [GitHub issues](https://github.com/aoneahsan/macleanup/issues) |

## Move across

1. Run the safe batch as a preview. The command line needs no account.

   ```bash
   npx macleanup --dry-run --all
   ```

2. Save the preview so you can read it slowly.

   ```bash
   npx macleanup --dry-run --all --no-color > ~/Desktop/macleanup-preview.txt
   ```

3. Preview apps you have not opened in 100 days, the default.

   ```bash
   npx macleanup --only 21 --dry-run
   ```

4. Run one section for real, not the whole batch.

   ```bash
   npx macleanup --only 8
   ```

Section 8 takes only your own top-level temp files at least two days old, and it
deletes them directly. A backup is the way back.
