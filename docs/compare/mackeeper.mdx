# Moving from MacKeeper

MacKeeper is a subscription with antivirus, a VPN, adware blocking and breach
monitoring around the cleanup. macleanup is only the cleanup. If you rely on any of
the others, line up a replacement for them before you touch your subscription;
nothing here stands in for them.

## Which part of the subscription this covers

| In MacKeeper | In macleanup |
|---|---|
| Junk files and unused apps | [`--profile minimal`](/reference/profiles) and [section 21](/reference/sections#section-21) |
| Uninstaller with leftover removal | Sections [21](/reference/sections#section-21) and [12](/reference/sections#section-12--orphaned-app-data) |
| Antivirus, VPN, adware blocking, identity monitoring | Nothing |
| 24/7 chat support | [GitHub issues](https://github.com/aoneahsan/macleanup/issues) |

## Trying it before you cancel anything

1. Preview the safe batch. The command line asks for no account.

   ```bash
   npx macleanup --dry-run --all
   ```

2. Write that preview to a file on your Desktop and read it at your own pace.

   ```bash
   npx macleanup --dry-run --all --no-color > ~/Desktop/macleanup-preview.txt
   ```

3. See which apps you have left unopened for 100 days, the default threshold.

   ```bash
   npx macleanup --only 21 --dry-run
   ```

4. Make the first real run a single small section, not the batch.

   ```bash
   npx macleanup --only 8
   ```

Section 8 removes only your own top-level temp files that are at least two days
old, and it deletes them directly. Only a backup brings them back.
