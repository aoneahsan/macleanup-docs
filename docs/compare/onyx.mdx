# Moving from OnyX

OnyX ships a separate build for each macOS version. macleanup is one script for
macOS 11 and later. If you open OnyX for its hidden
Finder, Dock and Safari settings, or to verify system files, keep it: none of that is
here. Its cleaning tasks are the part that moves, and each has a section number.

## OnyX's tabs, against the section list

| In OnyX | In macleanup |
|---|---|
| Deleting caches | Sections [5](/reference/sections#section-5--user-caches), [6](/reference/sections#section-6), [19](/reference/sections#section-19--browser-caches) and [27](/reference/sections#section-27--macos-ui-maintenance) |
| Uninstalling applications | [Section 21](/reference/sections#section-21), apps idle for a set number of days |
| Maintenance tasks | [Section 13](/reference/sections#section-13--system-maintenance-periodic) runs `periodic` and needs sudo |
| Hidden Finder, Dock and Safari settings | Nothing |
| Verifying system files, rebuilding databases | Nothing |

## Rebuilding your OnyX routine

1. Preview every cache layer as one profile. Logs come along with it.

   ```bash
   npx macleanup --profile cache-only --dry-run
   ```

2. No admin password at hand? Section 6 needs sudo, and with `--no-sudo` it is
   skipped whole rather than half-run.

   ```bash
   npx macleanup --profile cache-only --no-sudo --dry-run
   ```

3. Look for something OnyX never lists: data from apps you have removed.

   ```bash
   npx macleanup --only 12 --dry-run
   ```

4. Pick the one section you trust most, run it by itself, and read its prompt
   before answering.

   ```bash
   npx macleanup --only 7
   ```
