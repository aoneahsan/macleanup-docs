# Moving from Sensei

Did you buy Sensei for the menu bar gauges, drive health or benchmarks? Then keep
it; macleanup has no monitors, no S.M.A.R.T. readings and no benchmarks. What it can
take over is Sensei's cleaning tab and its uninstaller, and after every run it tells
you what it moved or removed.

## The cleaning tab, section by section

| In Sensei | In macleanup |
|---|---|
| Old caches and system logs | Sections [5](/reference/sections#section-5--user-caches), [6](/reference/sections#section-6) and [7](/reference/sections#section-7--logs) |
| Large downloads | [Section 18](/reference/sections#section-18--large-files-report), as a report |

| Uninstaller | [Section 21](/reference/sections#section-21) |
| CPU, GPU, battery and thermal monitors | [Section 0](/reference/sections#section-0--system-health-and-process-monitor) is a one-time text snapshot, not a monitor |

## Handing over the cleaning, keeping the gauges

1. Begin with the three reports. They write files and delete nothing.

   ```bash
   npx macleanup --only "0,15,18"
   ```

2. Preview the safe batch. No deep section is ever chosen by it.

   ```bash
   npx macleanup --dry-run --all
   ```

3. Clear logs on their own. The system-log half needs sudo; pass `--no-sudo` and
   that half is skipped entirely instead of half-run.

   ```bash
   npx macleanup --only 7 --no-sudo
   ```

4. Open the session summary. Attempted, completed, skipped and failed are counted
   apart: [Reports and logs](/reference/reports-and-logs).
