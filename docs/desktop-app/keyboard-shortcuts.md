# Keyboard shortcuts

**Every shortcut in the macleanup desktop app can be rebound.** These are the
defaults.

| Shortcut | Action |
|---|---|
| <kbd>⌘</kbd> <kbd>K</kbd> | Open the command palette |
| <kbd>⌘</kbd> <kbd>N</kbd> | Start a new preview |
| <kbd>⌘</kbd> <kbd>Y</kbd> | Open run history |
| <kbd>⌘</kbd> <kbd>,</kbd> | Open settings |

<kbd>⌘</kbd> <kbd>N</kbd> starts a preview, which changes no files.

## Rebinding {#rebinding}

One key combination maps to one action. If the combination you choose is
already bound, the app names the action that holds it and leaves both
unchanged until you pick another.

Your bindings are stored on your Mac. Signed in, they also sync with your
account and come back when you sign in on another Mac — see
[Privacy in the app](/desktop-app/privacy).
