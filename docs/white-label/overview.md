# White-label licence and buyout

A white-label licence puts macleanup under your name. We build the desktop
app, the command-line tool or both with your name, icon and colours, publish
them, and send each macleanup release to your users.

Prices are on the [white-label pricing page](https://macleanup.aoneahsan.com/white-label/pricing).
They are read from our licensing service, so this manual does not repeat them.

## What MIT already gives you {#mit}

The macleanup script is open source under the MIT licence. Anyone may read,
change and ship it on those terms, and `npx macleanup` has no limits.

A licence covers what MIT does not:

| | MIT | White-label licence |
|---|---|---|
| The script's code | Yes | Yes |
| The macleanup name and mark with your build | No | Yes |
| The desktop app (private code) | No | Built for you, code not included |
| Builds, publishing and updates run by us | No | Yes |

## Not exclusive {#exclusive}

We may license macleanup to other buyers until someone buys out the desktop app.

## The desktop app buyout {#buyout}

The desktop app's code is private. One buyer can buy it outright: the
macleanup-desktop repository changes hands with a period of updates, and
after that we stop selling macleanup white-label licences to anyone else.
The command-line tool stays public under MIT and is not part of the sale.
Licences sold before a buyout keep their terms. Details are on the
[buyout page](https://macleanup.aoneahsan.com/white-label/buyout).
